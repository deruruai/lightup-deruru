# LIGHT UP, DERURU! — 데루루 응원봉 리듬게임 (p5.js)

하트 노트가 원근 무대 레인을 따라 내려오면, 판정선의 응원봉 버튼을 터치해서 관객석을 응원봉으로 물들이는 리듬게임입니다.
5곡 × 3단계(새내기팬 · 찐팬 · 최애) — **이번 버전은 처음부터 모든 곡 · 모든 모드가 열려 있습니다.**

---

## 1. 여는 방법

| 방법 | MV 배경 | 하는 법 |
|---|---|---|
| **① MV와 함께 실행 (추천 · 윈도우)** | ✅ 나옴 | 폴더 안 **`MV와 함께 실행.bat` 더블클릭** → 크롬이 자동으로 열림 |
| ② 링크로 열기 (Claude 미리보기) | ❌ 무대 그림으로 대체 | 대화창의 게임 링크를 열기 — 폰에서도 바로 됨 |
| ③ index.html 더블클릭 | ❌ 무대 그림으로 대체 | 인터넷 없어도 됨 |
| ④ GitHub Pages (폰 시연용) | ✅ 나옴 | 폴더 파일 전부 올리고 Settings → Pages 켜기 → `https://아이디.github.io/저장소/` |

### ① `MV와 함께 실행.bat` 자세히
1. 압축을 푼 폴더에서 `MV와 함께 실행.bat` 를 더블클릭합니다.
2. 까만 창이 하나 뜨고, 잠시 뒤 크롬(기본 브라우저)에 게임이 열립니다. 주소는 `http://localhost:8137/index.html`.
3. **게임하는 동안 까만 창은 닫지 마세요.** 다 놀았으면 그 창을 닫으면 끝.
- 설치할 것 없음 (윈도우에 기본으로 있는 PowerShell 사용).
- "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행** 을 누르세요.
- 브라우저가 안 열리면 까만 창에 나온 주소를 크롬에 붙여 넣으세요.
- 맥은 터미널에서 폴더로 이동해 `python3 -m http.server 8137` 실행 후 `http://localhost:8137` 접속.

> 유튜브는 보안 정책상 **파일 더블클릭(file://)** 과 **Claude 미리보기 창** 안에서는 영상을 띄울 수 없어서,
> 이 두 경우에는 MV 대신 스테이지 배경 그림으로 자동 진행됩니다. 게임 자체는 똑같이 됩니다.

## 2. 조작

| | 휴대폰 | PC |
|---|---|---|
| 노트 치기 | 레인(화면 아래쪽)을 터치 | `D` `F` `J` `K` |
| 꾹 노트 | 빛 꼬리가 다 들어올 때까지 누르고 있기 | 키를 누르고 있기 |
| 떼창 TIME | 화면 아무 곳이나 연타 | 아무 레인 키 · `Space` 연타 |
| 일시정지 | 왼쪽 위 ❚❚ | `Esc` |

- **판정** : PERFECT / GOOD / MISS (모드가 높을수록 판정 범위가 좁아짐)
- **싱크로율** : PERFECT 1점 · GOOD 0.65점 평균 → **70% 이상이면 그 곡의 클리어 보상 일러스트 해금**
- **랭크** : S 95% · A 88% · B 75% · C 60% 이상
- **콤보 컷인** : 50 NICE~! · 100 GREAT!! · 200 AMAZING!!! (이후 100콤보마다) — 노트를 가리지 않도록 레인 위쪽 띠에 작게 나와요
- **떼창** : 곡마다 2구간. 떼창 컷인 후 게이지를 채우면 성공(+10000점, 관객석 전부 점등)
- **FULL COMBO** : MISS 0으로 끝나면 풀콤보 컷인


## 2-1. MV 화면

- 곡 선택 화면 아래 **▶ MV 화면 ON/OFF** 로 켜고 끕니다 (기본 ON).
- **폰(세로)** : MV 가 화면 맨 위에 16:9 로 나오고, 그 아래 점수 줄 · 레인이 이어집니다 (노트를 가리지 않음).
- **PC(가로)** : 게임은 오른쪽, MV 는 왼쪽 빈 공간에 크게 나옵니다.
- MV 가 켜지면 **MV 소리로 플레이**합니다 (게임 음원은 소리 없이 MV 를 따라가기만 함).
  판정도 MV 영상 시간 기준이라, MV 가 버퍼링으로 멈추면 노트도 같이 멈췄다가 이어집니다.
- 휴대폰이 MV 소리 자동재생을 막거나 MV 가 끊기면, 자동으로 **게임 음원 소리 + 소리 없는 MV 화면** 으로 바뀌어 계속됩니다.
- **처음 한 번은 곡마다 'MV 싱크 맞추기' 를 해 주세요.** (MV 앞에 인트로 영상이 있으면 그만큼 어긋나기 때문)
  1. 곡 선택 → 아래 **MV 싱크 맞추기**
  2. **1단계** : MV 가 처음부터 나와요. 노래 첫 소리가 들리는 순간 **"노래 시작!"** 버튼 탭 → 대충 맞춰짐
  3. **2단계** : MV 소리와 게임 음원이 같이 나와요. 노래가 **메아리처럼 두 번 들리면** ± 버튼(0.02 / 0.1 / 1초)으로 조절,
     **하나로 깔끔하게 들리면 "저장하고 돌아가기"**. MV 가 음원보다 늦으면 +, 빠르면 −.
  - 맞춘 값은 그 기기에 곡마다 저장됩니다. 맞춘 숫자를 알려 주면 `data/songs.js` 의 `mvOffset` 에 기본값으로 넣어 다른 기기에서도 맞게 할 수 있어요.
- MV 가 "다른 사이트에서 재생 금지"로 설정돼 있으면 (유튜브 오류 101/150) 그 곡은 무대 배경으로 진행됩니다.
  → 유튜브 스튜디오 → 동영상 → 세부정보 → 더보기 → **"퍼가기 허용"** 체크.

### 노트 속도 · 싱크 조절 (곡 선택 화면 아래)
- **노트 속도** 0.5x ~ 2.5x
- **싱크 조절** : 결과 화면의 '평균 타이밍'이 계속 +(느림)로 나오면 싱크 조절을 + 쪽으로, −(빠름)이면 − 쪽으로 맞추세요.
  블루투스 이어폰은 소리가 늦게 나서 +100ms 이상 필요할 수 있습니다.

## 3. 폴더 구조

```
LightUpDeruru_v2/
├─ index.html              실행 파일
├─ MV와 함께 실행.bat      더블클릭 → MV 배경 켜진 상태로 실행 (윈도우)
├─ serve.ps1               위 bat 가 쓰는 작은 웹 서버 (내 컴퓨터 안에서만)
├─ lib/p5.min.js           p5.js (폴더 안에 포함)
├─ data/
│   ├─ songs.js            곡 목록 · 색 · 보상 일러스트 이름
│   └─ charts.js           채보 5곡 × 3모드 (stem 분석 자동 채보)
├─ js/
│   ├─ core.js             공통 : 화면 크기 · 이미지/음악 불러오기 · 노래 시계 · 저장 · 효과음 · 버튼
│   ├─ fx.js               불꽃 파티클 · 데루루 컷인 합성 · 관객석 응원봉
│   ├─ mv.js               유튜브 MV 배경 (음원 시간에 맞춰 자동 보정)
│   ├─ main.js             p5 setup() / draw() · 화면 전환
│   ├─ scene_title.js      타이틀
│   ├─ scene_select.js     곡 선택 · 난이도 · 설정
│   ├─ scene_play.js       플레이 (원근 레인 · 판정 · 꾹 · 떼창 · 콤보 컷인)
│   ├─ scene_result.js     결과 · 해금 팝업
│   ├─ scene_gallery.js    보상 일러스트 갤러리
│   └─ scene_mvsync.js     MV 싱크 맞추기
└─ assets/
    ├─ img/                로고 · 하트 노트 · 레인 빛 (4색으로 미리 물들임)
    ├─ stage/<곡id>.webp   스테이지 배경 5장
    ├─ cutin/<곡id>_nice|great|amazing|fever.webp   컷인 캐릭터 20장
    ├─ illust/             클리어 보상 일러스트 5장 (+ 갤러리 썸네일)
    └─ music/<곡id>.mp3    음원 5곡
```

**곡 id** : `revolution` · `snowy-love` · `new-day` · `lollipop-devil` · `summer-breeze`

### 그림 바꾸기
같은 이름으로 덮어쓰면 됩니다. 원본(PNG)을 그대로 넣고 싶으면 확장자만 맞춰서 `core.js` 의 `loadAll()` 경로를 바꾸세요.
(웹에서 빨리 뜨도록 원본을 WebP로 줄여 넣었습니다. 컷인 600×800, 배경 810×1440, 보상 일러스트는 원본 1080×1920 그대로.)

### 컷인 합성 방식
캐릭터 PNG만 있으면 됩니다. 색 띠 · 글자(NICE~! 등) · 반짝이는 코드(`fx.js` 의 `Cutin`)가 그려서 합칩니다.
떼창 컷인과 풀콤보 컷인은 같은 `fever` 그림을 쓰고 글자만 다릅니다.

## 4. 시연 · 녹화용 주소 옵션

`index.html` 뒤에 붙여서 엽니다.

| 옵션 | 뜻 |
|---|---|
| `?auto=1` | 자동 플레이 (모든 노트 PERFECT · 떼창 자동) — 기록 · 해금은 저장 안 함 |
| `?song=revolution&mode=2` | 타이틀 건너뛰고 바로 그 곡 · 모드로 시작 (0 새내기팬 · 1 찐팬 · 2 최애) |
| `&seek=50` | 50초부터 시작 (테스트용) |

예) `index.html?song=snowy-love&mode=1&auto=1` → Snowy Love 찐팬 자동 플레이 (시연 영상 녹화용)

## 5. 알아둘 점
- MV 를 켜면 MV 소리, 끄거나 MV 를 못 쓰는 환경이면 음원 파일 소리로 플레이합니다.
- 기록 · 해금 상태는 **그 기기의 그 브라우저에만** 저장됩니다. 다른 폰에서 열면 처음부터.
- 스페셜(찐팬 풀콤보) · 시크릿 일러스트는 다음 버전에서 추가 예정 — 갤러리에 안내만 있습니다.
